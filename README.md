ConnectHub 
----------

ConnectHub is a basic web-based social media application inspired by Facebook, built using Java (MVC architecture) and MySQL.

---

Features

* User Authentication: Basic registration and login system.
* News Feed & Post Creation: Simple feed to view and create text updates.
* User Profiles: Basic user profile page.

---

Tech Stack

* Backend: Java (Servlets, JSP, MVC)
* Frontend: HTML, CSS, JavaScript
* Database: MySQL

---

How to Run Locally

1. Database: Import the SQL file from the database folder into phpMyAdmin.
2. Config: Set up your database password in DBConnection.java.
3. Run: Deploy and run on Apache Tomcat Server.
